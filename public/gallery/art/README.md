# Gallery artwork

Drop image files here, then point their entries in `src/islands/projectsData.js` at:

```
src: `${BASE}gallery/art/your-file.jpg`
```

Prefer JPG/WebP under ~400KB. Set `aspectRatio` to the real width÷height of the file so the mosaic stays justified.

Temporary Unsplash URLs in `projectsData.js` are placeholders — replace them with local files when ready.
